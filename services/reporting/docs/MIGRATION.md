# Хранилища и архивы

Рабочее развёртывание находится на VPS 172.105.249.196; выполнять старый сценарий
первичного переноса для его запуска не требуется. Актуальная карта — SERVER_GUIDE.md.

Сохранены рабочая БД activity_trial, архив activity_archive_20261025 и проверочная
activity_tenants_verify_20261024. База activity также существует; её удаление не разрешено
и она не объявляется источником текущего UI. Исходные пакеты/дампы — migration-trial/.
Архивы не используются как команды к действию и не удаляются при уборке документации.

Внешний Asana-бот остаётся отдельной зависимостью на 167.99.36.155.
Его обновление Review BDM подтверждено оператором. Это не альтернативный сервер дашборда.

Для будущего переноса нужны согласованный pg_dump, конфигурация, collector sessions,
входные пакеты и ui-state; проверка восстановления обязательна. Не копировать живые SQLite
без согласованного backup и не запускать одну Telegram-сессию одновременно на двух хостах.
