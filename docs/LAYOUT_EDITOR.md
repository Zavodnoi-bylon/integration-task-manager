# Расположение панелей

Администратор открывает «Настроить расположение», меняет порядок/размеры и сохраняет.
Сохранённая раскладка применяется ко всем пользователям с учётом их прав на панели.
Отмена отбрасывает черновик; исходный вид возвращает штатную раскладку.

Хранение: /home/teamactivity/ui-state/layout.json; web видит /var/lib/activity-ui/layout.json.
Формат version:1 хранит виджеты, span/height и необязательные column/row.
API проверяет ID и границы координат. Только admin может сохранять.

Реализация: src/layout-model.js, src/layout.js, src/style.css, activity/access.py.
В текущей реализации есть сообщённые пользователем дефекты: отступы режима редактирования
остаются в просмотре, перетаскивание может прыгать, отсутствует удобное автоматическое
уплотнение. Это не считается завершённым UI. Следующий подход ещё не выбран;
обсуждалась замена собственного механизма на готовый grid editor либо фиксированную раскладку.
При уборке документации раскладка и UI-код не изменяются.
