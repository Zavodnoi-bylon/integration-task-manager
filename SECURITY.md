# Security policy

Не добавляйте в Git токены Telegram, пароли PostgreSQL, рабочие `.env`, дампы,
SQLite-файлы, логи или выгрузки пользовательских сообщений.

Production-секреты хранятся только на сервере вне checkout в каталоге
`/home/teamactivity/.config/integration-task-manager` с ограниченными правами.
При компрометации токена его нужно перевыпустить через BotFather, обновить
соответствующий env-файл и пересоздать только затронутый контейнер.
