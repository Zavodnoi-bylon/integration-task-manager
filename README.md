# Team Activity Explorer

Отчётность отдела по рабочим Telegram-перепискам и уведомлениям Asana:
поступившие и завершённые задачи, известный открытый остаток, динамика и график смен.

**Начать с [карты сервера и инструкции](docs/SERVER_GUIDE.md).**
Это основной документ: адреса, работающие компоненты, файлы, данные, расписание и обслуживание.

- [Проверенное состояние](docs/STATUS.md)
- [Поток данных](docs/WORKFLOW.md)
- [Правила анализа](docs/EXTRACTION_PROMPT.md)
- [Смысл метрик](docs/BACKEND_SEMANTICS.md)
- [Разработка и проверки](docs/LOCAL_DEVELOPMENT.md)

Рабочая БД — PostgreSQL. API и UI учитывают принятые предложения с доказательствами.
Автоматический сбор сообщений сам по себе не означает автоматический смысловой анализ.
Синтетические примеры в examples/ используются только при явном demo-режиме.
